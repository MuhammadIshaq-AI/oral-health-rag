# Scope Dental Practice — patient assistant (web app)

Next.js app (App Router, Tailwind CSS v4) that serves both the chat UI and the RAG API. It deploys
to Vercel as a single project with no separate backend.

```
Browser ──> /api/chat (Vercel function)
              ├─ embed question (Gemini)
              ├─ search src/data/knowledge.json in memory
              └─ cited answer (Gemini 3.6 Flash)
```

## Local development

```bash
cp .env.example .env.local   # set GEMINI_API_KEY
npm install
npm run dev                  # http://localhost:3000
```

## Environment variables

| Variable | Required | Description |
|---|---|---|
| `GEMINI_API_KEY` | yes | Google AI Studio key; used only on the server |
| `LLM_MODEL` | no | Chat model, default `gemini-3.6-flash` |
| `CLINIC_MIN_SCORE` | no | Minimum similarity for practice passages to be included |

## Key files

| Path | Purpose |
|---|---|
| `src/app/api/chat/route.ts` | Validates input, retrieves passages, calls Gemini, returns answer + sources |
| `src/app/api/health/route.ts` | Reports whether the key is configured and how many passages are loaded |
| `src/lib/rag/` | `knowledge.ts` (loads vectors), `retrieve.ts` (search), `prompt.ts` (instructions, citations), `gemini.ts` (API client) |
| `src/data/knowledge.json` | Generated by `python scripts/export_web_index.py` in the repo root |
| `src/lib/brand.ts` | Practice name, phones, WhatsApp, Maps link, logo path |
| `public/brand/logo.png` | Practice logo (add it; the header falls back to a tooth icon) |

## Deploy on Vercel

Config: `vercel.json` (Next.js, `npm ci`, region `bom1`), `next.config.ts` (security headers),
`package.json` `engines` (Node.js 22), `.vercelignore` (no local env files in uploads).

1. Import the repo in Vercel and set **Root Directory** to `web`.
2. Add `GEMINI_API_KEY` under **Settings → Environment Variables**.
3. Deploy. From the CLI in this folder: `vercel link`, `vercel env add GEMINI_API_KEY production`, `vercel deploy --prod`.

See the [root README](../README.md) for how the knowledge base is built and evaluated.
